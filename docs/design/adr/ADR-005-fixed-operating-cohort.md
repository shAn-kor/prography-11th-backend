# ADR-005: 운영 기수 고정 정책

- Status: Proposed
- Date: 2026-02-26

## Context
현재 과제 요구사항은 운영 기수를 11기로 고정한다. 향후 운영 자동화를 고려하면 동적 전환 필요성이 생길 수 있다.

## Decision
- MVP 범위에서는 운영 기수를 11기로 고정한다.
- 단, 설정값 캡슐화를 통해 추후 DB/설정 기반 전환이 가능하도록 인터페이스를 분리한다.

## Alternatives Considered
- 즉시 동적화: 현재 요구 대비 과설계 가능성이 높다.
- 완전 하드코딩: 향후 변경 비용이 높아진다.

## Consequences
- 장점: 요구사항을 단순하게 만족하면서도 확장 여지를 남긴다.
- 단점: 전환 시 마이그레이션 ADR가 추가로 필요하다.
